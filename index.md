# Privacy Policy for CPS Net

Last Updated: June 12, 2026

## Introduction

CPS Net is a Discord bot that provides moderation tools, community features, entertainment commands, economy functionality, and AI-powered conversations.

This Privacy Policy explains what information CPS Net collects, how it is used, and what rights users have regarding their data.

## Information We Collect

CPS Net may collect and store the following information:

* Discord User IDs
* Discord Server IDs
* Discord Channel IDs
* AI conversation history submitted by users
* Economy-related user data required for bot functionality
* Bot configuration data necessary for server features

## How We Use Information

Collected information is used solely to:

* Provide AI conversation features
* Maintain conversation memory for users who choose to use AI features
* Operate economy-related systems
* Process commands and bot functionality
* Improve reliability and performance of the service

## AI Processing

Messages submitted to CPS Net's AI features may be sent to OpenAI for processing in order to generate responses.

Conversation history may be stored by CPS Net to provide memory and continuity between conversations.

Stored conversation data is not used to train CPS Net's own machine learning models.

## Data Storage

Data is stored only for as long as necessary to provide the bot's features and services.

Reasonable security measures are implemented to protect stored information from unauthorized access.

## Data Deletion

Users may permanently delete their stored data at any time using the bot's data deletion command.

When a deletion request is made, all associated stored user data is removed from CPS Net's systems.

## Data Sharing

CPS Net does not sell user data.

Data is only shared with third-party service providers when necessary to provide functionality, such as processing AI requests through OpenAI.

## User Rights

Users may:

* Request deletion of their data
* Stop using AI features at any time
* Remove the bot from servers they manage

## Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of CPS Net after changes are published constitutes acceptance of the updated policy.

## Contact

For privacy-related questions or requests, users may contact the CPS Net development team by sending a message to @va_. on Discord.

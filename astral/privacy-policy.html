Privacy Policy

Last updated July 15, 2026

Introduction

Astral is a Discord bot that provides moderation and auto-moderation tools, mod case logging, autoresponders, role management, welcome messages, community features, entertainment commands, and economy and utility functionality.

This Privacy Policy explains what information Astral collects, how it is used, and what rights users have regarding their data.

Information We Collect

Astral may collect and store the following information:

Discord User IDs
Discord Server IDs
Discord Channel IDs
Moderation case records (warnings, mutes, bans, kicks)
Economy-related user data required for bot functionality
Server configuration data (automod, autoresponders, roles, welcome messages, and other settings)

How We Use Information

Collected information is used solely to:

  • Provide moderation and auto-moderation features, including maintaining case records
  • Operate economy-related systems
  • Process commands and bot functionality, including autoresponders, roles, welcome messages, and utility and fun commands
  • Improve reliability and performance of the service

Data Storage

Data is stored only for as long as necessary to provide the bot's features and services.

Reasonable security measures are implemented to protect stored information from unauthorized access.

Data Deletion

Users may permanently delete their stored data at any time using the bot's data deletion command.

When a deletion request is made, all associated stored user data is removed from Astral's systems.

Data Sharing

Astral does not sell user data.

Data is only shared with third-party service providers when necessary to provide functionality.

User Rights

Users may:

  • Request deletion of their data
  • Remove the bot from servers they manage

Changes to This Policy

This Privacy Policy may be updated from time to time. Continued use of Astral after changes are published constitutes acceptance of the updated policy.

Contact

For privacy-related questions or requests, please contact the Astral support server.
